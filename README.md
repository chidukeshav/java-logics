## 🚀 How to Run

1. **Clone the repository:**

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. **Open the project** in Visual Studio Code or your preferred Java IDE.

3. **Compile a Java program:**

   ```bash
   javac FileName.java
   ```

4. **Run the program:**

   ```bash
   java FileName
   ```

   Replace `FileName` with the class name containing the `main` method.
